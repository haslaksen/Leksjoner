# Bilder og filer til leksjonene

Last opp her med **Add file → Upload files** på GitHub. Filen vises nederst i riktig del av leksjonen etter et par minutter.

Gi filen et navn som starter med leksjonsnummeret og delen, slik det står i den stiplede boksen på lærersiden (trykk «Vis/skjul plass for filer» i det røde feltet). Eksempel:

- `leksjon-4-herding-herdekar.jpg` vises i delen «Herding» i leksjon 4, med teksten «herdekar».
- `laerer-leksjon-4-herding-arbeidsark.pdf` vises bare på lærersiden.

Bilder (jpg, png, gif, webp, svg) og video (mp4, webm) vises på siden. Andre filer, som PDF og Word, blir en nedlastingslenke. Bruk små bokstaver og bindestrek i navnet. GitHub tar ikke filer over 25 MB; legg store videoer på YouTube eller OneDrive i stedet.
